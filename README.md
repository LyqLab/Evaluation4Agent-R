# Evaluation4Agent-R
基于固定虚构或历史人物角色的陪伴式角色扮演智能体能提供持续的情感陪伴，部分智能体已进入家庭、医院或长期护理机构以缓解孤独感。一项在所有已开展调查的地区均有大量成年人报告存在的问题。然而，其安全性评估仍采用针对普通聊天机器人设计的通用对话质量或内容危害指标，即便大型语言模型已应用于临床护理。此类指标虽可识别明显毒性，却无法判断角色是否在用户触及情感极限时保持连贯。现实中的陪伴对话已记录自伤、操控和边界侵犯行为。因此，当前评估体系无法解答的临床问题是：当情感脆弱的用户触碰智能体的界限时，角色是否会保持完整或以加剧心理风险的方式崩溃。
因此，我们开发了TriScena，这是一个三级框架，将智能体评估从角色一致性转移到角色的核心身份在看不见的安全和复杂场景下是否成立。除此之外，我们还建立了一个跨三个年龄组的15个维度的基准，每个年龄组有14个记忆、8个历史和8个前瞻性场景，并将Qwen3-8B微调为一个评估器，我们使用MAE和kappa来验证其与人类心理专家的一致性。然后，消融、跨平台和可扩展性实验证实了该框架的结构有效性和可推广性，从而产生了一种陪伴型角色智能体在进入用户生活之前，对其进行筛查的工具。
本研究的主要评估流程均通过自定义Python代码实现，该代码用于：角色档案建立、多模型驱动的智能体响应生成、原始样本构建、训练与测试数据集构建、评估机制及其他辅助功能。代码将在论文发表后在此公共仓库公开。代码基于Python 3.7.10开发，主要依赖以下库：openpyxl（>3.0）、pandas（>1.3）、transformers（>4.19）、numpy（>1.19）和scikit-learn（>0.24）。代码主要包括：（1）执行完整测试框架的多份脚本；（2）针对三个年龄组评估模型的训练超参数及脚本；（3）执行评估评分的计算脚本。除上述代码外，无需其他第三方定制软件。
